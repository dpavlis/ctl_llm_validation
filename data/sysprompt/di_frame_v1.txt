DataIntersection, as seen from CTL: the transform is a joiner over the matched pairs of the two sorted inputs. In transform(), $in.0 is the record from input 0 (A) and $in.1 the record from input 1 (B) with the same key, and there is exactly one output record, $out.0, with the transform's own output metadata. Fill $out.0 from the two inputs and return OK to emit it, or return SKIP to drop the pair. Records whose key is only on one side never reach the CTL; the component passes them on by itself, unchanged, on its other outputs, and that routing is not the CTL's business. The return value does not choose a port and there is no $out.1 or $out.2 in this transform.
